# Semitone Web

A tuner and metronome app, built in the spirit of the original
[Semitone](https://github.com/mkettn/semitone) Android app: same dark,
minimal look and feel, same cents-based pitch measurement — without the
piano (for now).

## Features

- **Tuner** — listens to the microphone and shows the detected note along
  with how far off pitch it is, in cents.
- **Metronome** — adjustable BPM, beat indicator, synthesized click
  sounds. Can optionally keep running when you switch away from its tab.
- **Scales** — the tuner always matches against whichever scale is
  active, switchable anytime from the app bar. Comes with five presets
  out of the box (Chromatic, plus the four genera of Byzantine chant
  theory), and you can create, copy, edit, export, or import your own —
  each with its own base frequency, so several scales can be tuned to
  different references at once.

## What's next

- **iOS**: the app builds for iOS today, but isn't signed or
  distributed yet — TestFlight/App Store availability is planned.
- **Piano**: a companion piano view, matching the original Semitone app.
